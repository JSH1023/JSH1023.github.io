🛡️ 모의 해킹 스터디용 PHP/MySQL 커뮤니티 웹사이트
InfinityFree 무료 호스팅 환경(PHP 8 + MySQL)에서 동작하도록 제작된 모의 해킹 실습용 커뮤니티 웹사이트 프로젝트입니다.

웹 보안 취약점 분석 및 웹 허점 진단 스터디를 위해 일부러 보안 검증 로직을 축소/생략한 상태로 구성되어 있습니다.

📌 주요 기능 및 구성
1. 사용자 및 인증
회원가입: 아이디, 비밀번호, 닉네임 입력 및 계정 생성

실시간 아이디 중복 확인: JavaScript Fetch API (check_id.php)를 활용해 페이지 새로고침 없는 비동기 검사

로그인 / 로그아웃: PHP 세션 기반 인증 상태 유지 및 해제

2. 마이페이지
내 정보 조회: 회원 아이디 및 프로필 사진 확인

정보 수정: 닉네임 변경 및 프로필 이미지 파일 업로드

3. 커뮤니티 게시판
게시글 목록: 전체 게시글 리스트 및 글쓰기 버튼 제공

글 작성: 제목, 본문 작성 및 파일 첨부 지원

글 상세보기: 게시글 본문/첨부파일 확인, 댓글 작성 및 삭제

글 수정: 작성자 본인의 게시글 제목/본문 수정

글 삭제 (delete_post.php): 작성자 또는 관리자의 게시글(연동 댓글 포함) 삭제

파일 다운로드 (download.php): 첨부파일 다운로드 로직 수행

4. 1:1 쪽지 기능
쪽지 보내기: 수신자 아이디 지정 후 메시지 발송

받은 쪽지함: 로그인 사용자에게 수신된 쪽지 목록 조회

5. 관리자 페이지 (admin.php)
회원 목록 관리: 전체 회원의 ID, 아이디, 닉네임, 관리자 권한(is_admin), 가입일 조회

게시글 통합 관리: 전체 게시글 모니터링 및 관리자 권한을 통한 즉시 삭제

🛠️ 기술 스택 및 환경 요구사항
Server/Language: PHP 8

Database: MySQL / MariaDB (mysqli 드라이버 사용)

Hosting Target: InfinityFree (무료 호스팅)

Frontend: HTML5, CSS3, JavaScript (Fetch API)

📂 파일 구조 및 DB 정보 설정
모든 DB 설정은 config.php 파일 한 곳에서 통제합니다.
