웹 애플리케이션 주요 취약점 정리 (XSS & SQLi)

작성일: 2026-09-19

본 포스팅에서는 스터디용 커뮤니티 웹사이트를 제작하고 직접 테스트해보며 확인한 핵심 보안 취약점을 정리합니다.

1. SQL Injection

사용자 입력값이 데이터베이스 쿼리로 직접 전달될 때 발생하는 취약점입니다.

// 취약한 쿼리 예시
$query = "SELECT * FROM users WHERE username = '$username' AND password = '$password'";

2. Cross-Site Scripting (XSS)

검증되지 않은 스크립트 코드가 브라우저에서 실행되는 취약점입니다.

<script>alert('XSS Test');</script>
