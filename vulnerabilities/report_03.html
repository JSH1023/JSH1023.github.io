3. 발견한 취약점 상세

🚨 발견된 주요 취약점 목록

  1. SQL Injection (인증 우회): 로그인 폼에 ' OR '1'='1 구문 입력 시 비밀번호 검증 없이 로그인 우회 성공
  2. Stored / Reflected XSS: 글 제목 및 댓글에 HTML/JS 스크립트 입력 시 이스케이프 없이 그대로 렌더링되어 실행됨
  3. HttpOnly 속성 미설정: 세션 쿠키에 HttpOnly 플래그가 누락되어 XSS를 통한 쿠키 탈취 가능
  4. IDOR (부적절한 접근 제어): 수정 버튼을 거치지 않고 Direct URL 요청(edit.php?id=*)으로 타 사용자의 게시글 수정 접근 가능
  5. 웹셸 / 실행 파일 업로드: 파일 업로드 시 검증 로직이 부재하여 서버 측 실행 파일이 그대로 업로드됨
  6. 우회 파일 업로드: 확장자만 우회한 위장 파일(예: MIME/확장자 변조 파일)도 검증 없이 업로드 허용

4. 미확인 항목 및 점검 한계

  1. 파일 삭제 기능 부재

    애플리케이션 내 파일 삭제 인터페이스가 존재하지 않아 관련 접근 제어 및 취약점 점검을 진행하지 못함.

5. 결론 및 종합 의견

  • 점검한 기능: 로그인, 회원가입, 게시판, 글 작성/수정, 프로필 페이지 등
  • 확인된 취약점: SQL Injection, XSS, 인증/세션, IDOR, 파일 업로드 등 (다수 발견)
  • 우선 수정할 항목: 파일 업로드 취약점 (원격 코드 실행 위험) 및 SQL Injection

종합 의견

진단 대상 애플리케이션 점검 결과, 웹셸 업로드가 가능한 파일 업로드 취약점 및 인증 우회가 가능한 SQL Injection을 포함하여 핵심 기능 전반에 걸쳐 고위험 취약점이 다수 발견되었습니다. 특히 서버 권한 탈취로 이어질 수 있는 파일 업로드 검증 로직 구현과 Prepared Statement 적용을 통한 SQLi 방어가 시급히 이뤄져야 합니다.
