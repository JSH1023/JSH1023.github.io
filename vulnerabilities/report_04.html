3. 발견한 취약점 상세

🚨 세션 쿠키 내 HttpOnly 속성 미설정 (취약)

심각도: 보통 (Medium)

심각도 분석: 로그인 시 발급되는 세션 쿠키에 HttpOnly 속성이 설정되어 있지 않아, 추후 XSS 등 추가 취약점과 연계될 경우 자바스크립트를 통해 세션 쿠키가 그대로 탈취될 위험이 있습니다.

[그림 3.1] 로그인 세션 쿠키 내 HttpOnly 속성 미설정 확인 화면

상세 내용: 로그인 기능 이용 시 개발자 도구를 통해 확인한 세션 식별자 쿠키에 HttpOnly 플래그가 누락되어 있음을 확인하였습니다. 이에 따라 클라이언트 단의 자바스크립트(document.cookie) 명령을 이용한 쿠키 접근이 가능한 상태입니다.

대응 방안: 서버 측에서 세션 쿠키를 발행할 때 HttpOnly 및 Secure 속성을 함께 적용하여 비인가된 자바스크립트의 쿠키 접근을 원천 차단해야 합니다.

4. 미확인 항목 및 점검 한계

  1. 검색 기능 부재로 인한 Reflected XSS 한계

    애플리케이션 내 검색 입력 폼이 존재하지 않아 Reflected XSS 취약점의 안전 여부를 직접 파악하기 어려움.

  2. 파일 업로드 기능 부재

    첨부파일 및 프로필 사진 등 파일 업로드 관련 인터페이스가 없어 해당 항목 진단은 미확인 처리함.

5. 결론 및 종합 의견

  • 점검한 기능: 회원가입, 로그인, 마이페이지, 쇼핑몰, 커뮤니티 게시판 등 전반적인 웹 서비스 기능
  • 확인된 취약점: 인증 및 세션 관리 영역 (HttpOnly 속성 미설정)
  • 우선 수정할 항목: 세션 쿠키 HttpOnly 설정 적용

종합 의견

SISEON 서비스 대상 취약점 진단 결과, SQL Injection, XSS, IDOR 등 주요 웹 공격 벡터에 대해서는 전반적으로 안전(양호)한 상태를 유지하고 있음을 확인했습니다. 다만, 로그인 세션 쿠키 발급 시 HttpOnly 속성이 미설정된 보안 설정 미흡 사항이 식별되었으므로, 세션 보호 강화를 위한 쿠키 속성 패치가 우선적으로 적용되어야 합니다.
